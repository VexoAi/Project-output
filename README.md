# Video Generation for Studies - Demo 7

This repository contains the study video generation platform designed to transform educational notes and teacher audio into interactive animated video lessons.

## 🚀 Repository Structure

- **`main`**: Primary core web application (`index.html`, `app.js`, `style.css`, `data.js`, `modules/`).

### 👥 Contributor Branches

Each contributor's dedicated module is available on its respective branch:

- 🧪 [**`adthiya`**](https://github.com/VexoAi/Project-output/tree/adthiya): Chemistry lesson player, atomic structure simulations, and periodic table animation engines.
- ⚡ [**`brangin`**](https://github.com/VexoAi/Project-output/tree/brangin): Physics renderer, curriculum logic, and audio teaching engine.
- 🎨 [**`deepika`**](https://github.com/VexoAi/Project-output/tree/deepika): Visualizer component library (Math, English, Science, Solar System & Grammar labs).
- 🎙️ [**`deva`**](https://github.com/VexoAi/Project-output/tree/deva): Biology curriculum engine, voice commands, and interactive smart questions.
- 🎬 [**`dharani`**](https://github.com/VexoAi/Project-output/tree/dharani): Anime character renderer, temporal video compiler, and WebM video generator.
- 🌐 [**`eirik`**](https://github.com/VexoAi/Project-output/tree/eirik): Frontend canvas suite, storyboard editor, and sound FX engines.
