# 🎙️ BioBuddy Voice Commands Reference Guide

BioBuddy features full hands-free voice control powered by the Web Speech Recognition API. Below is the complete table of recognized natural language voice commands.

---

## 🔬 1. Topic Navigation Commands

| Spoken Phrase | Action / Target Module |
| :--- | :--- |
| `"Open DNA"` / `"Genetics"` / `"Gene"` | Loads DNA Double Helix & Punnett Square Lab |
| `"Open Circulatory"` / `"Heart"` / `"Cardio"` | Loads 4-Chamber Heart & Blood Flow Lab |
| `"Open Respiratory"` / `"Lungs"` / `"Breathe"` | Loads Diaphragm & Alveoli Gas Exchange Lab |
| `"Open Brain"` / `"Nervous System"` / `"Neuron"` | Loads Brain Anatomy & Synapse Impulse Lab |
| `"Open Photosynthesis"` / `"Plants"` / `"Chloroplast"` | Loads Chloroplast Solar Reactor Sandbox |
| `"Open Cell"` / `"Cell Structure"` / `"Microscope"` | Loads Plant vs Animal Cell Microscope |
| `"Open Microbes"` / `"Bacteria"` / `"Microorganisms"` | Loads Virtual Agar Petri Dish Incubator |
| `"Open Digestive System"` / `"Stomach"` / `"Food"` | Loads 5-Stage Digestive Tract Journey |
| `"Open Animal Classification"` / `"Taxonomy"` | Loads Vertebrates & Invertebrates Classifier |
| `"Open Ecosystem"` / `"Food Chain"` / `"Food Web"` | Loads Trophic Pyramid & Population Graph |

## 🧪 2. In-Lab Actions & Gamification

| Spoken Phrase | Action Triggered |
| :--- | :--- |
| `"Start Quiz"` / `"Quiz me"` / `"Challenge"` | Opens the Topic Knowledge Challenge modal |
| `"Tell me a fact"` / `"Bio fact"` / `"Trivia"` | Dr. Helix speaks a random fascinating bio-fact |
| `"Open Glossary"` / `"Dictionary"` / `"Terms"` | Opens the searchable Biology Quick Glossary |
| `"View Badges"` / `"Portfolio"` / `"Certificate"` | Opens the Science Portfolio and Certificate |

## 🧬 3. Hands-Free Simulation Controls

| Spoken Phrase | Simulation Effect |
| :--- | :--- |
| `"Unzip DNA"` / `"Replicate"` | Toggles Helicase unzipping / complementary strand replication |
| `"Deploy Macrophage"` / `"White blood cell"` | Spawns an amoeboid macrophage that engulfs pathogens |
| `"Add Antibiotic Disc"` / `"Antibiotic"` | Places filter paper disc creating Zone of Inhibition |
| `"Trigger Drought"` | Simulates severe drought (plant biomass drops) |
| `"Add Wolves"` / `"Predators"` | Introduces apex predators to restore ecosystem balance |
| `"Send Impulse"` / `"Action potential"` | Fires electrical impulse down the neuron axon |
| `"Switch to Plant Cell"` | Changes microscope lens to Plant Cell with chloroplasts |
| `"Switch to Animal Cell"` | Changes microscope lens to Animal Cell |
| `"Day mode"` / `"Night mode"` | Switches solar light exposure on chloroplasts |
